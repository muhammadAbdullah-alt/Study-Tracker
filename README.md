# Study & Task Tracker

A single-page task and study tracker that helps you manage daily tasks, track study goals and count your steps — all saved in your browser.

**Live demo:** https://task-tracker-ochre-six.vercel.app/

## Features

- Add tasks with a title, category and priority (High / Medium / Low)
- Mark tasks complete, delete them, and filter by category
- Live stats: total, completed and pending tasks
- Step tracker with a customisable daily goal (default 10,000 steps)
- Live clock
- Everything is saved in localStorage — no account, no backend

## Tech

HTML • CSS • Tailwind CSS • JavaScript • Vite

## Run it locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
